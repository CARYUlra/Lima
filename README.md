## 📖 Sobre o Projeto

Este repositório contém a resolução da atividade sobre **Linguagens de Marcação**, focando na compreensão das diferenças estruturais, aplicabilidades em projetos reais, vantagens e limitações das linguagens **HTML**, **XML** e **Markdown**.

A atividade inclui uma pesquisa teórica aprofundada sobre o **XML** e a entrega dos exercícios propostos devidamente corrigidos e testados.

---

## 🎯 Objetivos

- **Classificar e Diferenciar:** Compreender o papel específico do HTML (estruturação web), XML (transporte/armazenamento de dados) e Markdown (formatação simplificada de texto).
- **Análise Crítica:** Identificar as vantagens, limitações e cenários ideais de aplicação para cada linguagem.
- **Pesquisa em XML:** Aprofundar o entendimento sobre validação, tags personalizadas e sintaxe bem-formada em XML.
- **Prática com Versionamento:** Organizar e disponibilizar os arquivos resolvidos utilizando Git e GitHub.

## 📚 Conteúdos Abordados

| Linguagem | Foco Principal | Exemplo de Aplicação |
| :--- | :--- | :--- |
| **HTML** *(HyperText Markup Language)* | Exibição de conteúdo e estruturação de páginas web. | Sites, aplicações web, e-mails HTML. |

🔍 Pesquisa Aprofundada: XML
A pesquisa desenvolvida neste projeto aborda os seguintes pontos chave da linguagem XML:

Sintaxe Bem-Formada: Regras essenciais (tag de fechamento, diferenciação de maiúsculas/minúsculas, aninhamento correto e elemento raiz único).

Tags Personalizadas: Como a liberdade de definição de elementos torna o XML independente de plataforma.

Validação: Diferença entre um XML apenas bem-formado e um XML válido (uso de DTD e XML Schema / XSD).

XML vs JSON: Análise comparativa sobre o uso de XML em sistemas legados/integrações corporativas em contraste com o JSON em APIs REST modernas.
